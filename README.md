# Wilbert Andrew Yonathan — portfolio

A responsive internship portfolio preserving the navy, royal blue, orange and soft white palette, iOS system typography, glass surfaces and subtle space animation. Static HTML, CSS and JavaScript; no build step, visitor account or paid AI API is required.

## Included

- Profile, nine relevant courses, six projects, resume-aligned skills, language capabilities, achievements, leadership and contact.
- Project readers with contributions, results, limitations, credits, real screenshots and shareable `#project=` links.
- Eight original certificate images across five entries, with document selectors and downloads.
- dPickleball source and competition video; an organizing-role certificate attached separately under leadership.
- Search, filters, local shortlist, command menu, curated portfolio assistant and mobile navigation.
- Skippable WAY laser opening, word detection outlines, navigation reticle and stars. Reduced-motion preferences and hidden tabs pause decorative motion.

The projects are Marine detection, PaddyLiteX, dPickleball, Res UCN, facial expression recognition and NeuroInsight Alzheimer’s disease classification. The three expandable exploration sections are removed. Each project's case study retains its own evidence and results.

October 12 update: PaddyLiteX reports 81.67% mAP@0.5, 55.83% mAP@0.5:0.95, 2,879,917 parameters and 14.2 reported GFLOPs. Its comparison distinguishes the DenseNet-121 baseline from original YOLOv8n. NeuroInsight uses the supplied Streamlit home-page screenshot, with the original evaluation image available in its gallery. Its revised case study describes the nine classifier families and three labels documented in the renamed Alzheimer-Disease-Classification repository. The Canva presentation could not be read; presentation-specific results are not added.

## Main files

`dist/index.html` contains the page; `projects.js` stores project content; `media.js` supplies imagery; `details.js` handles readers/viewers; `credentials.js` lists the certificate files. `details.css` extends the existing design. `assistant.js` answers from the curated portfolio.

See `CERTIFICATES.md` for the document inventory and `DEPLOY-VERCEL.md` for deployment. The supplied review HTML embeds necessary assets for local review. This package has not changed the live Vercel site.

Project order: PaddyLiteX, Marine, dPickleball, Res UCN, FER, Alzheimer classification. Periods follow Wilbert’s supplied dates. Languages: English, Mandarin, Indonesian, Malay and Hokkien; proficiency ratings are not inferred.
