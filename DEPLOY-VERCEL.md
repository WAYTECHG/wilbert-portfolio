# Deploy the reviewed portfolio

The existing live site is https://wilbert-andrew-yonathan.vercel.app/. This package has not been deployed there.

After reviewing the HTML demo, replace the complete `dist` folder in the connected GitHub repository. Keep root `vercel.json`. Delete obsolete images named in `CERTIFICATES.md`; uploading files alone does not remove old files. Commit when ready to update production, or use a separate branch for a preview.

| Setting | Value |
| --- | --- |
| Framework preset | Other |
| Root directory | Repository root |
| Build command | Empty |
| Install command | Empty |
| Output directory | dist |
| Environment variables | None |

Certificates are included and linked. Test each document selector, full-document link and download, plus project readers, YouTube, search, mobile navigation, chatbot and résumé links.
